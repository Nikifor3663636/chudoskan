ЧудоСкан

Сканер товарів «Чудо Острів»

Android

Завантажте файл і відкрийте його — телефон запропонує встановити.

Завантажити APK
  1. Якщо з'явиться «Заблоковано» — натисніть «Налаштування» і дозвольте встановлення з цього браузера.
  2. Нова версія ставиться поверх старої, дані зберігаються.

iPhone

Спершу поставте безкоштовний застосунок TestFlight від Apple, потім натисніть кнопку ще раз.

Встановити через TestFlight

Версія для iPhone готова й проходить перевірку Apple.
