# ЧудоСкан Друк

Програма для комп'ютера магазину, до якого підключено **Godex**. Телефони продавців надсилають етикетки 40×24,
а програма друкує їх на Godex. Brother сюди не підключається: він друкує з телефонів напряму по Wi-Fi.

Windows 10 або 11. Права адміністратора не потрібні, ключі вводити не треба.

## Встановлення в 3 кроки

1. **Завантажити установник** з [релізів](https://github.com/Nikifor3663636/chudoskan/releases?q=printer-v&expanded=true)
   (останній `printer-v…`): `ChudoScanPrint-…-x64.exe` для звичайної 64-бітної Windows, `…-x86.exe` — для 32-бітної.
2. **Запустити установник** → «Далі» → «Встановити». Програма стане в `%LOCALAPPDATA%\Programs\ChudoScan Print`,
   запускатиметься сама після входу в Windows (значок біля годинника) і одразу відкриє вікно з кодом.
3. **Підключити до магазину:** у застосунку на телефоні адміна магазину — «Профіль → Принтери →
   Підключити комп'ютер» → ввести 6 цифр із синьої смуги вікна. Смуга стане зеленою: «Працює».

Код діє 15 хвилин, потім програма сама покаже новий.

## Вікно програми

| Смуга | Що означає |
|---|---|
| 🟢 **Працює** | Підключено до магазину, Godex готовий |
| 🔵 **Підключіть комп'ютер** | Великий код і скільки він ще діє |
| 🔴 **Потрібна увага** | Godex не знайдено, вимкнено, немає паперу, відкрита кришка… |
| ⚪ **Немає зв'язку** | Немає інтернету — програма під'єднається сама |

- **Тест етикетки** — надрукувати пробну етикетку на Godex.
- **Спробувати ще** — перевірити зараз, не чекаючи.
- **Журнал** — `%LOCALAPPDATA%\ChudoScan\logs` (без паролів і токенів).
- **Відключити від магазину** — друк з телефонів на цей Godex зупиниться, з'явиться новий код.
- Хрестик ховає вікно в значок; повний вихід — правою кнопкою по значку → «Вийти».

## Для розробника

```
ChudoScan.Print.Core/    net8.0: Godex з WMI, код підключення, черга, загальний стан, тестова етикетка
ChudoScan.Print.Tests/   xUnit
ChudoScan.Print/         net8.0-windows, WinForms: вхід Firebase (анонімно), FirestoreGateway (REST), друк RAW
installer/               Inno Setup: без прав адміністратора, автозапуск HKCU\…\Run
```

```bash
dotnet test ChudoScan.Print.Tests
```

Збірка установників — [`.github/workflows/printer.yml`](../.github/workflows/printer.yml): Web API key і projectId
бере із секрету `GOOGLE_SERVICES_JSON`; тег `printer-vX.Y.Z` публікує реліз. У консолі Firebase має бути увімкнено
**Authentication → Anonymous**.
